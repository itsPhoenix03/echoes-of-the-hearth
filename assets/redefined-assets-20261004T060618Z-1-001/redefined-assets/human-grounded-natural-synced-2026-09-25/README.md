# Human animation synchronization and expressions

This supersedes human-grounded-natural-smooth-2026-09-24. It includes the same 10 replacement-ready base names and the same 213 animation frame names across 25 actions; dimensions and viewBoxes remain unchanged. In held-object actions, weapons, tools, plants, and vials are now anchored to the animated hand within the body's motion group. Attached effects and bandages follow the body; only ground/environment pieces stay outside. Faces have more distinct action and phase expressions.

Open preview.html for playback, frames.png for all poses, and expressions.png for enlarged faces. Previous sprites are in before/ for comparison. No game code was modified. Frame timing and registration in the game are still needed before these additional animations play in runtime.
