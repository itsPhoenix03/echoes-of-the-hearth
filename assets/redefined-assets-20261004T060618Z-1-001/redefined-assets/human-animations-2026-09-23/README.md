# Human character animation frames

75 optional SVG frames for five refined characters. Each frame uses the same width, height, and viewBox as its character base in the human-characters-refined-2026-09-23 batch. Naming: `<character>_<action>_01.svg` to `_03.svg`. Play in order at about 6–10 fps for most actions; shiver can loop faster, and sitting should hold frame 02. These frames are not wired into the game. The replacement-ready base filenames remain unchanged in the previous character batch.

Actions:
- keeper: attack, collect, build, shiver, sweat, swim, sit, injured, meds, dig
- villager: walk, collect, build, sit
- villager2: walk, collect, craft, sit
- medic: walk, heal, prepare
- medic_snow: walk, heal, prepare, shiver
