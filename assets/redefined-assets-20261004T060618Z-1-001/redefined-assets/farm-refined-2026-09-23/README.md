# Farming sprite batch

Replacement-ready SVGs: farmplot.svg 64×40 and crop.svg 30×34, with unchanged filenames and canvas sizes. The farmplot is intentionally empty tilled soil; planting is represented by the separate crop overlay. Current art copies are under before/.

Optional new assets: crop_sprout.svg (30×34) for young wheat; crop_sway_01..03.svg (30×34) for mature-wheat wind motion; glowcap_young.svg (44×42) for the early mushroom crop; grain.svg (30×30) for a harvested inventory icon. The game currently displays stage 1 by scaling the mature crop and uses an emoji for grain. The optional files need code integration to appear. The full-grown glowcap art already exists in the underground batch. No codebase files were changed.
