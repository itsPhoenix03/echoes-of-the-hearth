# World scenery refinement

21 replacement-ready SVG sprites in sprites/, with identical filenames and canvas sizes to the current game assets. Original versions are in before/sprites/ for comparison. Open preview.html or preview.png to compare.

This batch covers stone, ice, volcanic, vegetation, small world props, medic huts, ruins, gate, watchtower, and windmill. It does not modify game code, tiles, modular building pieces, UI, or raw materials.
