# Enemy art batch

Nine existing replacement-ready base SVGs keep their current names and canvas sizes: blight-creature, stalker, brute, wisp, drowned, blight_lancer, golem, blight_spore, blightheart. Current art is copied in before/ for comparison.

Three optional standalone variants: bog_shambler, frost_wraith, husk_wolf. The current game uses blight-creature, wisp, and wolf for these enemy types respectively; these optional files need code registration before use.

Each enemy has a three-frame optional motion set under sprites/animations/ or sprites/optional/. The current game uses procedural sprite gait and does not play these files yet. No codebase files were changed.
