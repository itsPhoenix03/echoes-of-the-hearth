# Crafted structures, walls and floors

This is a complementary update to the workbench wood kit. The new bed.svg supersedes that kit's bed: a continuous rectangular mattress/blanket fills the bed top, with closed box sides and no open corner gaps.

Replacement-ready sprites: bed; mod_banner_blank (the current banner texture); stone_blocks, clay_bricks; campfire, forge, shelter, engine; all three modular floors (wood, stone, thatch); all three modular walls (wood, stone, crystal). Each keeps its current filename and canvas size. The stone path uses mod_floor_stone in the current game. Original files are in before/ for comparison.

No other modular categories were changed. No codebase files were changed.
