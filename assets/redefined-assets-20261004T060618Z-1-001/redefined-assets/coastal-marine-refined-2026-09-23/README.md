# Coastal and marine animal batch

Replacement-ready base SVGs with original filenames and canvas sizes: crab.svg 30×20, seal.svg 62×40, fish.svg 30×16. New optional species: shark.svg 76×40 and dolphin.svg 70×38.

Each animation uses three frames named `<species>_<action>_01.svg` through `_03.svg`. Actions: crab scuttle/claw; seal swim/flop; fish swim; shark swim; dolphin swim/leap. They are art assets only and require code integration to play. Shark and dolphin also require code registration/spawning. No codebase files were changed.
