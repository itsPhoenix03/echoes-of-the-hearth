# Workbench materials and wooden pieces

Twelve replacement-ready SVGs, with the same names and canvas dimensions as the current game assets. Original files are under before/ for comparison.

- Intermediate materials: wood_planks, stone_blocks, rope_coil, cloth_roll, reed_thatch.
- Direct workbench objects: chest, wall, bed. The current recipes use wood/fiber directly, not planks.
- Modular pieces: mod_floor_wood, mod_wall_wood, mod_door, mod_railing. These use the intermediate materials; door and railing use both planks and rope.

The modular pieces are manifest-registered but may need further gameplay wiring. No codebase files were changed.
